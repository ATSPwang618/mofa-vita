# 架构总览

当前目标：`KNIF00540`，PS Vita 原生 GXM，960×540 演出与合成，960×544 显示居中上下各2像素。脚本布局坐标保留1920×1080；单张纹理的物理尺寸另由素材头与离线预算决定。引擎基于 AuroraWright/knife 0.9.4；桌面 WGPU 后端保留作为开发对照。

| 目录 | 职责 |
|---|---|
| `knife/knife/src` | VM、Game/Stage、UI、字体、资产与存档 |
| `knife/knife-core` | MZX/MZP、NX/KATL/KIMG与归档格式解析 |
| `knife/knife-render`、`knife-render-api` | 命令录制、共享几何/材质、Vita与桌面后端 |
| `knife/knife-platform-vita` | Rust平台接口、GXM FFI、输入、音频、存储、启动检查 |
| `knife/vita` | 原生C GXM、GPU生命周期、Cg程序及第三方依赖 |
| `knife/knife-audio`、`knife-perf` | 音频混音、计时、优化配置及共享预算 |
| `tools` | 构建、离线Shader、素材处理、生产解析器盘点与验证 |

主执行链：归档与脚本 → VM/motion → Stage绘制列表 → 资源准备/命令录制 → GXM提交 → display queue。资源尚未准备完成时使用已有等待/恢复策略；不要绕过失败把不完整帧或存档当作有效结果。

资源工作线程负责有界读取与解码，GXM注册/上传和GPU生命周期由渲染路径管理。脚本推进、资源就绪、GPU提交与显示完成是不同事件，不能只看CPU占用判断瓶颈。

生产存档与DEV探针命名空间分离。Vita固定中文ID2，资源包保留英语与澄空中文。玩家手动快进关闭，正常自动播放保留；存档恢复所需内部seek不因此移除。

实际入口：[vita_entry.rs](../knife/knife/src/vita_entry.rs)、[game.rs](../knife/knife/src/game.rs)、[Stage](../knife/knife/src/stage.rs)、[渲染后端](../knife/knife-render/src/vita.rs)。
