适用范围：本仓库 Vita 引擎的构建、原生依赖、着色器生成、VPK 打包、发布验证与故障处理；桌面构建只简要提及。
代码基线：`perf/render` 提交 `a670193`（当前工作树为同一提交 + 文档重构，代码未改）。所有 `path:line` 以该基线源码为准。
标记约定：**[代码]** 可在当前源码/脚本核对；**[历史实测]** 来自历史真机捕获（r2/r3/r4，捕获分辨率 480×270/720×404，不等于终版 960×540）；**[未验证]** 仓库内无证据或需实机/模拟器确认。
历史出处：旧 `doc/archive/` 已在本次重构清理；历史记录见 git 提交 `a670193` 的 `doc/archive/`（工作树已清理）。

## 2. 快速开始

```bash
python3 tools/build-vita.py --check       # 只读体检：不安装、不编译
python3 tools/build-vita.py game release  # 正式包
```

不带参数等价于 `game release` [代码] `tools/build-vita.py:322-323`；`release` 只允许 `game` [代码] `:334-335`。Windows 用 `py -3` 代替 `python3` [代码] `tools/build-vita.ps1:15-29`。

- `--check`：逐项报告 SDK 候选、工具版本、Rust 状态与仓库依赖哈希；就绪返回 0，否则 1 [代码] `tools/build-vita.py:197-212`、`:353-354`。
- `--setup`：只安装缺失的 rustup/固定 nightly/`rust-src`，不构建 [代码] `:215-241`、`:324-326`。
- 普通构建先做同样体检；缺失 Rust 会自动安装 [代码] `:355-360`。

### 4.4 可复现性：路径重映射与 ELF 脱敏

- 构建前生成 `CARGO_ENCODED_RUSTFLAGS`，对 `$HOME→/home/builder`、`CARGO_HOME→/cargo`、`RUSTUP_HOME→/rustup`、`VITASDK→/vitasdk`、仓库根`→/source`、`CARGO_TARGET_DIR→/build/target` 加 `--remap-path-prefix`（真实路径与 resolve 两种拼写）[代码] `tools/build-vita.sh:137-160`。

- 签名前 `arm-vita-eabi-strip --strip-debug`，再跑 `tools/sanitize-vita-elf.py`：只允许等长替换 `.rodata` 中继承自预编译 SDK 的**源文件名**，代码段逐字节不变、布局/大小/符号不变，发现异常路径即拒绝 [代码] `tools/sanitize-vita-elf.py:1-8`、`:43-72`。
- 链接额外 `--undefined=` 四个符号（`_newlib_heap_size_user`、`sceLibcHeapSize`、`sceUserMainThreadStackSize`、`sceUserMainThreadPriority`），防止 `--gc-sections` 消掉内存/栈常量 [代码] `tools/build-vita.sh:171-174`。

## 6. 着色器：生成、编译与缓存

### 6.1 运行时效果着色器

唯一源文件 `knife/vita/shaders/effects.cg` 被生成器逐行转义为 C 字符串，写入 `shaders/generated/runtime_source.h`，同时生成源码 SHA-256、编译器 SHA-256/字节数、导出表偏移与 entry ABI 宏 [代码] `tools/generate-runtime-shaders.py:9-33`、`runtime_source.h:4-8`。修改 `.cg` 后必须重新生成：

```bash
python3 tools/generate-runtime-shaders.py
```

CMake 配置阶段会跑 `--check`，过期直接失败，避免「改了源码却编进旧 shader」[代码] `knife/vita/CMakeLists.txt:6-12`。

### 6.2 离线 GXP 头（基础着色器）

`shaders/generated/effects.h`、`shaders.h` 为离线编译的预编译程序，普通构建不需要 Sony 工具 [代码] `knife/vita/effects_backend.inc:2`、`knife/vita/gxm_backend.c:12`。只有修改基础着色器时才需要 `psp2cgc`：

```powershell
.\tools\compile-vita-shaders.ps1 -Compiler (Get-Command psp2cgc.exe).Source
.\tools\compile-vita-effects.ps1  -Compiler (Get-Command psp2cgc.exe).Source
```

不传 `-Compiler` 时按 `KNIFE_VITA_CGC` → PATH 中 `psp2cgc(.exe)` 顺序探测，找不到给出明确错误 [代码] `tools/compile-vita-effects.ps1:1-23`。

### 6.3 运行时缓存

设备首次启动若 `ux0:/data/knife-vita/shader-cache/` 中 10 个专用程序未全部命中，才加载 `libshacccg.suprx` 编译并落盘；缓存键为「源码 SHA + 编译器 SHA + 编译策略 + 缓存 ABI + entry ABI + shader id」，文件名即键，写入用临时文件 + rename，校验失败删除重建，全部命中时**不加载编译器** [代码] `knife/vita/runtime_shaders.c:24`、`:151-201`、`:331-343`；失败回退离线 GXP [代码] `knife/vita/effects_backend.inc:39-45`。完整机制见 [02-渲染与GPU后端](02-渲染与GPU后端.md)。

## 8. 修改着色器与系统图片
