# 构建与工具链

## GitHub Actions（本地新增，尚未云端运行）

`.github/workflows/vita-release.yml` 在分支 push 或手动触发时构建，使用 VitaSDK 2026.08 和 nightly-2026-05-28。产物包含 VPK、EBOOT、构建收据及 SHA256SUMS，保留 30 天；`v*` 标签另触发 GitHub Release。CI 显式设置非静默日志。工作流不会因本地编辑而自动执行，需用户明确要求推送后才会上云。

此流程沿用本地未压缩 SELF 构建脚本；没有移植远端的 `vita-make-fself -c` 改动。

从仓库根目录运行；编译引擎无需游戏素材。Windows包装入口用于调用WSL；本机直接在WSL中执行已验证。本机可用发行版`pocket-ubuntu`、VitaSDK位于`/opt/vitasdk`；Vita固定`nightly-2026-05-28`及rust-src。桌面Rust版本与Vita工具链分开。

```bash
python3 tools/build-vita.py --check
python3 tools/build-vita.py game release

```

Windows PowerShell 本机已验证的入口：

```powershell
wsl.exe -d pocket-ubuntu -- bash -lc 'cd /mnt/d/AI-CODEX/mofa-vita && KNIFE_BUILD_TAG=perf-render-20261109-213051-210a811-story-font-local KNIFE_VITA_QUIET=0 KNIFE_PERF_CONSOLE=1 python3 tools/build-vita.py game release'
```

`py -3 tools/build-vita.py --wsl pocket-ubuntu ...` 包装路径本机出现 `wslpath` 反斜杠转义失败，尚未修复；使用上面的直接 WSL 入口。版本时间按本地 `perf/render` 基准提交，未提交修改带 `-local`，实际成品由 SHA256 和构建收据进一步区分。

仅`game`允许release。开发探针仍保留platform/gxm/image/effects/audio/pipeline/text/audio-mixer/movie/compressed/ui-color等入口，不能因正式包未调用就删除其平台接口。

| 设置 | 用途 |
|---|---|
| `KNIFE_BUILD_TAG` | 启动日志和收据版本号；每次交付应明确设置 |
| `KNIFE_VITA_OPTIMIZATIONS=hardware-test` | 当前候选配置，包含独立对照开关 |
| `KNIFE_PERF_CONSOLE=1`、`KNIFE_VITA_QUIET=0` | 默认VitaDeck日志 |
| `KNIFE_VITA_OFFLINE=1` | 禁止Rust下载，Cargo使用offline |
| `KNIFE_VITA_CACHE` | 可再生成的编译缓存位置 |
| `KNIFE_VITA_ATTRIBUTE2=12` | 当前扩展MAIN内存属性；不是365MiB堆保证 |

release无限运行、生产存档命名空间；DEV通常有限帧运行、独立诊断存档。依赖、模块和许可证按当前构建脚本校验，不能把可再生成缓存与vendor输入混淆。

## 产物与交付

构建暂存：`.work/vita/game-release-540p/`，包含EBOOT、内部名称VPK、ELF/map、SFO和`vita-game-release-540p-build.json`。

**正式交付目录固定为仓库根目录 `release/`**（本机 `D:\AI-CODEX\mofa-vita\release\`）：

- `mofa-vita.vpk`：安装包，固定名称。
- `eboot.bin`：同版本程序，供 VitaDeck 更新。

`python3 tools/build-vita.py game release` 成功完成打包、包检查及收据生成后，先校验包内EBOOT与独立文件一致，再更新上述两个文件。DEV探针使用各自VPK名称，不覆盖正式游戏EBOOT。GitHub Actions也从这两个路径收集产物。

游戏素材仍保留在 `dist/Witch-on-the-Holy-Night-Chengkong-540p-Vita/assets/`。后续正式打包无需人工复制程序到dist；日志默认开启，交付前保留上一版小体积程序回退文件。
