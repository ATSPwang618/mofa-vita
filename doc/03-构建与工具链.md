# 构建与工具链

从仓库根目录运行；编译引擎无需游戏素材。Windows入口自动调用WSL。本机可用发行版`pocket-ubuntu`、VitaSDK位于`/opt/vitasdk`；Vita固定`nightly-2026-05-28`及rust-src。桌面Rust版本与Vita工具链分开。

```bash
python3 tools/build-vita.py --check
python3 tools/build-vita.py game release
# Windows指定发行版
py -3 tools/build-vita.py --wsl pocket-ubuntu game release
```

仅`game`允许release。开发探针仍保留platform/gxm/image/effects/audio/pipeline/text/audio-mixer/movie/compressed/ui-color等入口，不能因正式包未调用就删除其平台接口。

| 设置 | 用途 |
|---|---|
| `KNIFE_BUILD_TAG` | 启动日志和收据版本号；每次交付应明确设置 |
| `KNIFE_VITA_OPTIMIZATIONS=hardware-test` | 当前候选配置，包含独立对照开关 |
| `KNIFE_PERF_CONSOLE=1`、`KNIFE_VITA_QUIET=0` | 默认VitaDeck日志 |
| `KNIFE_VITA_OFFLINE=1` | 禁止Rust下载，Cargo使用offline |
| `KNIFE_VITA_CACHE` | 可再生成的编译缓存位置 |
| `KNIFE_VITA_ATTRIBUTE2=12` | 当前扩展MAIN内存属性；不是365MiB堆保证 |

release无限运行、生产存档命名空间；DEV通常有限帧运行、独立诊断存档。依赖、模块和许可证按当前构建脚本校验，不能把可再生成缓存与vendor输入混淆。

## 产物与交付

构建暂存：`.work/vita/game-release-540p/`，包含EBOOT、VPK、ELF/map、SFO和`vita-game-release-540p-build.json`。成功构建还复制VPK到`release/`，它是暂存副本，不是第二套长期运行包。

交付目录：`dist/Witch-on-the-Holy-Night-Chengkong-540p-Vita/`。同名`eboot.bin`用于VitaDeck，`knife-vita-540p.vpk`用于安装。发布前校验二者EBOOT一致、素材profile匹配、日志默认开启；保留最新ELF/map及源码身份收据。仅清理源码时不覆盖用户正在测的r12二进制。

## 验证入口

```bash
RUST_TEST_THREADS=1 cargo +nightly-2026-05-28 test --manifest-path knife/Cargo.toml --locked -p knife -p knife-render -p knife-perf
python3 tools/offline_vita_shaders.py --check
python3 tools/check-vita-package.py dist/Witch-on-the-Holy-Night-Chengkong-540p-Vita/knife-vita-540p.vpk KNIF00540 --release
python3 tools/generate_vita_asset_profile_540.py --check
```

渲染改动另跑`test-vita-gxm-*`、`test-vita-effects-inputs.sh`、`test-vita-material-variants.py`及对应像素回放。共享优化状态的host测试串行执行。ARM check证明目标代码可编译，完整ARM链接/VPK验证与实机像素/FPS验证是另一个层次。

shader改动先更新作者源、生成源/SHA和离线GXP；只改Rust选路而未同步C验证/反射不算完成。构建收据记录源码、配置及工具身份；清理历史临时文件不会改变其历史含义。
