# 构建与工具链

2026-11-17 核对，源码基线 `06415b5`。从仓库根目录执行；VitaSDK 本机路径 `/opt/vitasdk`，WSL 发行版 `pocket-ubuntu`，固定 Rust `nightly-2026-05-28` + rust-src。

## 常规入口

```bash
python3 tools/build-vita.py --check
python3 tools/build-vita.py game release
```

Windows 本机使用直接 WSL 入口；包装器的 Windows 路径转义曾失败，不将其作为已验证入口：

```powershell
wsl.exe -d pocket-ubuntu -- bash -lc 'cd /mnt/d/AI-CODEX/mofa-vita && KNIFE_VITA_QUIET=0 KNIFE_PERF_CONSOLE=1 python3 tools/build-vita.py game release'
```

通用构建默认 `KNIFE_VITA_OPTIMIZATIONS=hardware-test`，不含新 R6–R10 全部选项。复现最近候选的配置，在 WSL/bash 中执行：

```bash
export KNIFE_BUILD_TAG=perf-render-20261117-142048-06415b5-large-image-r10
export KNIFE_VITA_OPTIMIZATIONS='hardware-test,viewport-reject,group-mask-reject,ps-normal-multiply,live-alpha-coverage,cold-cohort,save-bgm-focus,shader-cap-batch,transition-textures,group-mask-clip,coverage-materials,group-opaque-mask,stage-opaque-cover,group-opaque-overwrite,transparent-draw-reject,stage-alpha-region'
export KNIFE_VITA_QUIET=0
export KNIFE_PERF_CONSOLE=1
python3 tools/build-vita.py game release
```

该标记标识已有交付，不应给后续源码改动重复使用；新交付追加唯一维护后缀/构建时间并保存哈希。R10 为 55 项启用配置，mask `0xcffffcfdfffffff`，不是所有候选已完成实机验收的声明。

## 产物与构建行为

- 正式交付固定为 `release/mofa-vita.vpk`、`release/eboot.bin`。包检查通过且两份 EBOOT 一致后才替换交付文件。
- `.work/vita/game-release-540p/` 保留 ELF/map、SFO、内部 VPK 和构建收据。最近旧程序回退在 `.work/package-large-image-20261117/previous/`。
- 当前游戏包通过 `vita-make-fself -s -c` 生成压缩 SELF；压缩程序不改变纹理编码或分辨率。
- `KNIF00540`、`ATTRIBUTE2=12`；newlib 堆为 256 MiB。扩展 MAIN 属性不等于整个 365 MiB 都可用作堆。
- release 无运行帧数上限，使用生产存档，默认日志开启；DEV 探针具有独立用途，不覆盖正式游戏 EBOOT。
- 构建会检查离线 GXP 与依赖身份；实际资源在设备外部读取，编译不要求整套游戏数据。
- `KNIFE_VITA_OFFLINE=1` 禁止下载；缓存缺失时应明确补依赖。ARM 缓存缺省在 WSL `~/.cache/knife-vita`，不属于仓库占用。

## 验证

```bash
RUST_TEST_THREADS=1 CARGO_TARGET_DIR="$HOME/.cache/mofa-vita-host" cargo +nightly-2026-05-28 test --manifest-path knife/Cargo.toml --locked -p knife -p knife-render -p knife-perf -p knife-core -p knife-audio -p knife-platform-vita
python3 tools/offline_vita_shaders.py --check
python3 tools/check-vita-package.py release/mofa-vita.vpk KNIF00540 --release
```

宿主测试需要桌面依赖，不能代替 GXM 像素检查。原生池/压缩/复制、材质输入等变更还应跑相应 `tools/test-vita-*.sh`；固定回放生产入口已移除，不能要求新包读取 `gpu-replay.txt`。

`generate_vita_asset_profile_540.py --check` 当前读取散装 `stream/`，不能直接验证只有 `voice.mrg/bgm.mrg` 的包；不要为运行它重新解包或覆盖现有资源。当前配套包校验记录见 [08](08-素材与安装.md)。

## GitHub Actions

`.github/workflows/vita-release.yml` 在分支 push、`v*` 标签或手动触发时构建；标签流程发布，普通构建上传产物。它收集 `release/` 下两个正式文件及收据。当前工作流未显式设置 R10 profile，不能把 CI 默认包当成本地 R10 包；也不因本地维护自动执行。是否成功以对应云端运行记录为准。
