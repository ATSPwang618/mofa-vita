## 读日志

### 更换网络后收不到日志

FTP/启动命令与游戏日志是两条连接：VitaDeck连接实机的FTP地址，实机CatLog则主动连接电脑IP的TCP 8080端口。只修改VitaDeck右侧的PS Vita IP，不会同步修改CatLog目标。

2026-11-09排查：实机172.17.25.100、电脑172.17.25.1；`ur0:data/catlog.cfg`仍指向10.195.41.1。已备份并只修改该12字节配置的前4字节为新电脑IPv4，保留8080端口、日志级别和网络开关，FTP读回一致。设备`perf-enable.txt=1`、PC接收器及当前程序的防火墙规则正常。本地TCP探针验证了接收器，但不算实机日志恢复验收。

CatLog内核模块启动时读取配置；直接FTP改文件后需保存游戏并重启实机重新加载。重启后确认VitaDeck收到来自实机的新连接以及实际游戏build_tag。配置备份和核对记录位于`.work/vitadeck-network-20261109/`。以后换网络时同时核对两端IP，不需要因此重打EBOOT。

- `sample`、`frame_window`、`frame_classes`：对齐相同帧边界，区分重绘与复用。末尾PC不是整个窗口的固定相位。
- `gpu_work.program_counts`：成功执行程序计数；ready只表示可选。105–107为r11组混合入口，88–104为r10材质入口。
- `estimated_covered_pixels`：裁剪后三角形的保守物理覆盖估计，重叠重复计；不是硬件fragment计数或GPU耗时。
- `batch_wait`/完成等待：CPU等待GPU工作的观测，不是独立GPU计时；嵌套计时不能直接相加。
- `resource_event`、错误链、stage读失败：区分卡读、NX输出、CPU解码、上传与GPU分配。总空闲不代表连续块。
- `save_focus`：r12仅状态改变时输出；page/slot/row/col从0开始，focus8–27为格子、28–33为页码；含tabrow、hit、frame_texture_ready。离开selection=null。纹理存在不等于GPU像素正确。
- `console_dropped_batches`：缺失窗口不插值；PC接收器多连接补丁见[工具](../tools/vitadeck/README.md)。

## 固定回放与离线盘点

`tools/vita_gpu_replay.py`分析生产Stage冻结回放。ABBA每块预热30帧、测120帧，固定素材、时钟与相位；要求相应B路径实际命中、A路径不命中，再评估RGBA8差分和整帧中位数/p95/p99。单个相位通过不等于全游戏正确性。

`tools/script_census.py`调用生产MZX/Scene解析器；盘点249场景，明确动态/未知参数，不要求玩家先通关。默认完整输出放`.work/reports/script-census.json`；仓库保留精简身份统计[evidence/29-script-census-summary.json](evidence/29-script-census-summary.json)，逐指令原报告可从Git恢复。离线盘点不声称运行或像素等价。

```bash
python3 tools/script_census.py --self-test
python3 tools/script_census.py --output .work/reports/script-census.json
```

没有同相位A/B时只报告观察值；不得将不同窗口的耗时节省累加为承诺FPS。20FPS对应50ms/帧，重绘低于这个预算才是持续演出改善。

## r14 资源压力诊断

启动核对`stage-effect-r14-resource-guard-20261109`。`resource_event.status`新增`pressure_reclaim`、`allocation_retry`、`allocation_recovery`，分别表示释放缓存引用/退休、原请求重试、实际帧上传升级回收结果。`optional_target_bytes`或`optional_bytes`仅为部分缓存释放请求估计，不是即刻内核空闲增量。

`resource_checkpoint`记录`status=saved/failed/unavailable`及scene/PC；detail含恢复点、自动槽和Archive标记。该关键持久化结果独立于周期perf开关写console；只有写盘成功才显示“进度已保护”。若只有failed/unavailable，不能认为进度已经落盘。记录本版配套ELF/map后再解析崩溃。
