# 上游同步与版本

## 基线

本工程基于 `knife` **0.9.4**（`knife/Cargo.toml`），加上 Vita 移植改动。
上游 `AuroraWright/knife` 在 2026-10-26 至 10-29 之间连续发版到 **0.9.9**，并在 10-29 之后
继续提交（TrueType hinting 解释器、复合字形）。

## 0.9.5 – 0.9.9 的变化与移植判断

| 版本 | 内容 | 移植 |
|---|---|---|
| 0.9.5 | 菜单/画廊/CG 浏览器的动画与 Switch 一致；CG 浏览器关闭修复；音乐播放器修复 | 未做，低优先 |
| 0.9.6 | `mod_assets` 目录与 `-m` 资源替换 | 未做（可作汉化扩展基础） |
| 0.9.7 | 按窗口尺寸渲染 | 不适用（Vita 固定 960×544） |
| 0.9.8 | iType 光栅化器（约 170 KB）；各语言换行规则（`kinsoku.rs` 26 KB）；亚像素取整；跳过预读 + 多核解码；选项高光修复 | 换行字符表**已移植**；其余见下 |
| 0.9.9 | `-f/\-\-fullscreen` | 不适用 |

## 已移植：换行字符表

本地排版循环与上游用同一个 N 公式：

```
N = floor((W - g/2) / (g + spacing)) + 1
```

并已有「不可行首」判断，只是字符表比上游少（缺全角 `：；`、`】》`、`～`、`ゎヮヵヶ` 等）。
现已把 `NO_LINE_START` 换成上游 `kinsoku::WITCH.no_start` 的同一条字符串，并补上
`NO_LINE_END`（`WITCH.no_end`）。

## 未移植：iType 光栅化器

规模：`knife-core/src/itype/` 8 个文件约 170 KB（CFF 37 KB、TrueType 22 KB、光栅 16 KB、
RTGA 67 KB、hinting 解释器）。

- 收益：字形、微调、轮廓与 Switch 一致；
- 未做原因：① 与文字放大模糊无关；② hinting 在 Vita 的 ARM 上逐字形执行，需先测 CPU 开销；
③ 上游该部分仍在快速迭代。

## 已移植但需注意差异

- 跳过时的预读：Vita 侧用后台线程 + 24 MiB 环形缓冲实现，效果与上游的「多核解码」接近
  （670 ms → 6 ms/条），但实现不同。
- 亚像素取整：本移植的场景放置已按整数像素对齐，未做上游那套「half-pixel」修正。
