# 已知限制与验证边界

2026-11-17 源码基线06415b5；最新成品身份见[安装](08-素材与安装.md)。

1. **没有全游戏最低FPS保证。** 历史r10记录的12.75FPS等结果属于当时包，不能归给新large-image/R10候选。当前完成代码整合、host、ARM和包/资源校验，仍需实机画面与长期运行验证。
2. **不是所有优化全游戏生效。** shader按材质选路；透明支持域依赖特定素材哈希；`group-opaque-overwrite`还受scene38指定演出阶段门控。当前材质不合格或程序不可用会回退。
3. **高清分块也有回退。** KQTL不覆盖所有Haze、mask、UV等材质组合；不能承诺所有演出都使用高清块。DXT为有损压缩，未命中离线变体的调色/raw等路径仍可能产生RGBA。
4. **内存恢复有边界。** 有限重试不能解决永久缺文件、坏数据、持续超过预算或设备故障。保护存档必须有最近有效点且写盘成功，不能保证恢复到失败指令的半完成状态。
5. **PNG路径变了。** `decode_native_image`对PNG使用Rust image并输出RGBA8；灰度R8优势不能泛化到此分支。字形R8及其他独立路径仍保留。
6. **素材制作工具链不完整。** 本版运行包已通过身份校验，但不能由现有旧工具无条件一键重做；KQTL制作与部分支持域生成器缺失，profile生成器尚按散装stream读取。不要覆盖现有包试错。
7. **固定GPU回放入口已删除。** 旧分析脚本保留，新版没有完整同EBOOT ABBA入口。设备像素等价和因果性能收益不能仅由host测试证明。
8. **当前输入策略开放快进/回退。** 和旧四按钮禁用版不同。字号确认写盘失败也会关闭菜单；配置持久化需复测。

## 不作为已交付收益的内容

- sparse-coverage旧实验默认关闭；不能与新增哈希绑定的live-alpha支持域混称。
- Half/Tiled/Blur/Scene容量2虽在候选中启用，仍不代表已完成全游戏逐项像素与性能验收。
- 历史降分辨率实验、任意多层大shader、错误mask替代、全包调色板和AT9迁移不是本版方案。
- Vita3K宿主OpenGL/Vulkan、host数学和原生mock均不能代替实机GXM验证。
