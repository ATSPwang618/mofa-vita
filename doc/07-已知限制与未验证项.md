# 限制与验证边界

当前交付通过主机侧资源、清单绑定与 VPK 检查，最新包尚未完成 Vita 实机画面、
性能和长期稳定性验收。历史设备结果见[证据索引](evidence/README.md)，不自动延伸到新包。

- **重建依赖和验证范围。** 原数据文件夹之外仍需密钥、固件字体及锁定工具。
  生产配方含历史编码差分；其他编码器或系统环境不能直接承诺同 SHA。
  当前采用分阶段转换与缓存续跑，清空全部转换缓存的单次全量重建尚未验收。
- **没有全游戏帧率保证。** 主机测试、构建通过、程序 ready 和单项命中分别证明不同事情。
  Half、Tiled、Blur、Scene 容量及各类融合仍需对应实机像素与性能对照。
- **优化有资格条件。** shader 按材质选路，透明支持域绑定素材哈希，
  `group-opaque-overwrite` 还受指定演出阶段门控；
  旧 sparse-coverage 默认关闭，不能将这些路径描述为任意图片全游戏生效。
- **高清块有回退。** KQTL 不覆盖所有 Haze、mask 和 UV 组合。
  DXT/PVRTC 为有损编码，raw、特殊调色及 PNG 路径仍可能展开 RGBA；
  不能承诺所有演出始终使用高清块或不再申请 CPU 图片内存。
- **恢复能力有限。** 有界回收无法解决永久坏数据、持续超预算和设备故障。
  保护存档要求最近有效节点与成功写盘，不保证回到故障指令。
- **输入与持久化需实机检查。** 书签栏按钮和快捷键策略不同；
  设置确认先关菜单再分别写文件，写盘失败不会留在菜单等待重试。
- **旧 GPU 回放已退出生产。** 历史分析工具仍保留，
  Vita3K、宿主数学检查及原生 mock 不能代替设备 GXM 验证。
