## 素材合同与编辑

清单 schema 为 `knife-540p-assets-v1`，method 为 `native-540p-encoded-unorm-v2`，颜色合同 `encoded-unorm8-v1`。资源保留英语/澄空中文，Vita 固定中文 ID2。KIMG codec9 为当前原生 GXT，codec8 历史 Alter 预烘焙包不能混用。

- 唯一可编辑工程：`dist/Witch-on-the-Holy-Night-Chengkong-540p-Compact-image-source/`，PNG 输入不能直接替代运行归档。
- 原版提取步骤见[中文](10-Switch原版资源提取.md) / [English](10-switch-asset-extraction.en.md)；当前没有已验证的一键复现完整同身份运行包的命令。
- [quality540](../tools/quality540/README.md)：保留逻辑坐标、长图、alpha 与语言条带；部署还须应用离线显存限额与验证。
- [UI 范围工具](../tools/prepare_vita_ui_ranges.py)：只改 KATL 外层布局，逐成员校验图像原字节。
- [感谢页](../tools/credit-intro/README.md)与 [PS 帮助页](11-可选交互更新.md)：分别使用对应制作链；后者内嵌于程序，不要求更换游戏归档。
- 改动视频等受校验资源后，更新清单、profile 及相应 atlas/stream 索引，再构建程序。单独替换 `logo.mp4` 会触发大小校验，不能删除校验绕过。

```bash
python3 tools/generate_vita_asset_profile_540.py --check
python3 tools/credit-intro/apply_credit_intro.py --check
```

## 操作与失败恢复

剧情顶栏第1、2、4、5项保持灰色禁用：上一场景、回退、快进、下一场景。自动播放、书签、语音与正常推进保留。L+□ 菜单可调整剧情字号50%–150%（每档5%），○保存、×取消，配置写入 `story-font-size.txt`。背板 L2/R2 默认关闭；不会重新启用被禁用的剧情功能，详见[交互说明](11-可选交互更新.md)。

资源最终失败且显示“进度已保护”后，重启并选择“继续游戏”。恢复最近成功显示的有效节点，自动槽122会更新，手动和快速槽保留。Archive 回放仍为回放，不会据此解锁尚未完成的主线。持续超限、坏数据和设备故障仍可能失败，见[资源保护](04-资源调度与缓存.md)。
