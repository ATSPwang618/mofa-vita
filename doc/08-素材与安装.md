## 编辑与再生成

- 唯一可编辑工程：`dist/Witch-on-the-Holy-Night-Chengkong-540p-Compact-image-source/`。PNG目录是输入工程，不能直接复制替代运行归档。
- [quality540](../tools/quality540/README.md)：一次缩放/一次DXT编码，保留逻辑坐标、长图、透明与语言条带。当前部署还须运行离线显存限额及验证。
- [UI范围工具](../tools/prepare_vita_ui_ranges.py)：只改选中KATL外层布局，验证成员字节与清单；不把NXZ扩展名当压缩依据。
- [感谢页](../tools/credit-intro/README.md)：保留源图、更新脚本及首两条原内容，新增两页按现有颜色合同打包。
- 修改视频或任意受校验文件后更新清单、profile及相关atlas/stream索引，再构建配套程序。只换logo.mp4会触发WRONG FILE SIZE，不应删除校验绕过。

```bash
python3 tools/generate_vita_asset_profile_540.py --check
python3 tools/credit-intro/apply_credit_intro.py --check
```

按键、音频、语言和存档不随仓库清理变更。保存原有玩家数据；设备操作日志与程序版本必须匹配。成品原始收据见[evidence/39-r12-save-focus.json](evidence/39-r12-save-focus.json)，本轮源码维护不冒充新的实机包。
