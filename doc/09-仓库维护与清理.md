## 维护流程

1. 盘点实际引用、文件体积与未提交改动，保存资源元数据及当前程序/符号身份。
2. 修改文档与可确认的死代码；平台接口按调用条件判断，保留有效测试。
3. 按改动运行 host、ARM、包/资源检查；生成程序后核对独立 EBOOT 与 VPK 内 EBOOT 一致。
4. 删除前核对每个绝对路径属于仓库且不存在联接/符号链接；使用 PowerShell LiteralPath，不执行全库 `git clean -fdx`。
5. 记录实际删除结果、保留校验及失败项；逻辑字节与实际磁盘占用分别表述。
6. 默认不提交、不推送；写远端必须有用户明确指令。
