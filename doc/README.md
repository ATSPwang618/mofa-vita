# 文档总览

本目录是 **mofa-vita 当前工作树**的技术文档集（基线：`perf/render` 提交 `a670193` + 2026-10-31 文档重构）。代码是唯一事实来源；文档中的数字/结论凡涉及设备表现，均区分：

- **[代码]**：当前源码常量或协议；
- **[历史实测]**：仓库归档的 r2/r3/r4 真机捕获（分辨率 **480×270 scene + 720×404 composite**，**不等于终版 960×540**；270p 变体已移除，480×270/720×404 仅为历史捕获分辨率）；
- **[未验证]**：仓库内没有设备日志/像素证据。

> ⚠️ 不要把历史实测的 FPS/ms 当作终版成绩；终版固定 960×540，scene 像素是捕获版的 4 倍。详见 [07-已知限制与未验证项](07-已知限制与未验证项.md)。

  git ls-tree -r --name-only a670193 -- doc/archive

## 维护约定

1. **代码优先**：文档与代码冲突时以代码为准，并在同一提交/工作树内同步文档。
2. 修改以下内容时需同步对应文档：
   - 渲染 pass/批次/依赖/着色器 → 02；优化开关/收益 → 05；
   - 资源格式/缓存/预算/线程 → 04；
   - 构建脚本/依赖/打包 → 03；
   - 采集指标/日志格式/分析工具 → 06；
   - 素材清单/TITLE ID/安装路径 → 08 与根 `README.md`。
3. 新增的真机证据放 `doc/evidence/`（或外部链接），不要恢复旧 `doc/archive/` 到工作树；历史出处引用 git 提交号。
4. 任何未上机验证的结论必须标注 `[未验证]`，不得把 host 测试/结构预测写成实测收益。
5. `doc/logs/` 是本地构建/测试日志目录（被 `.gitignore` 排除），不属于文档内容。
