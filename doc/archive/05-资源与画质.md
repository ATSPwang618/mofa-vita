# 资源与画质

## 纹理管线

游戏数据是 Switch 的归档格式（`jallpac` / `jallpachd` / `allui` 等）。移植把能预压缩的纹理
离线转成 Vita 的 GXT：

1. 逐条读出 KIMG 条目；
2. 应用默认 Alter 烘焙（脚本层的调色）；
3. 全不透明 → **DXT1**，含 alpha → **DXT5**；
4. `psp2gxt` 封装为 GXT，并按运行时解析规则自校验；
5. 写回归档。

打包工具：`tools/stage-vita-gxt-cg.py`、`tools/stage-vita-gxt-menu.py`、`tools/pack_dxt_540.py`。
转换后约 66% 的纹理为 GXT（23,054 张），其余 12,671 张保留原 PNG/JPEG（体积或画质更优者）。

运行时 GXT 直通 GXM：不展开为 RGBA，显存占用与带宽都更低；代价是压缩块伪影，
对平坦色块（UI）影响小，对渐变更明显的图保留原格式。

## 分辨率档位

| 场景链 | 画布 | 说明 |
|---|---|---|
| **480×270** | **720×405** | **默认**：场景省 GPU，文字仍较高分辨率 |
| 480×270 | 960×540 | `full`：文字原生清晰，慢约 1.5 倍 |
| 720×405 | 720×405 | `720`：整体更慢，仅作对照 |
| 240×135 | 720×405 | `quarter`：极限对照 |
| 960×540 | 960×540 | `native`：最高画质 |

切换方式：`ux0:data/knife-woh-540p/scene-mode.txt`（不存在即默认）。

## 文字清晰度

文字画在「合成/UI 画布」上，默认 720×405，再放大到 960×544 输出：

- 720×405 是已确认可接受的下限；
- 960×540 原生文字更清晰，但对白帧时间约增加 1.5 倍；
- 字形由 `ab_glyph` 光栅化进 R8 图集（每页 1024×1024，保留当前页与上一页）。

上游 0.9.8 把光栅化器换成了 iType 移植（字形/微调与 Switch 一致，约 170 KB 代码）。
移植它能改善**字形形状**，但不解决**放大带来的模糊**，因此优先级低于画布分辨率的取舍。

## 内存

| 项 | 预算 |
|---|---|
| newlib 堆 | 192 MiB |
| MAIN（ATTRIBUTE2=0x0C） | 365 MiB |
| CDRAM（后端自管） | 64 MiB 上限，含 JPEG 硬件预留 |
| 字体图集 | 单字体 24 MiB 上限，一次只保留一份 |

纹理缓存与 GPU 驻留策略各 32 MiB；加载失败走延迟重试而不是崩溃。
