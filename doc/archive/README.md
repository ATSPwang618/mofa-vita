# 历史文档归档

这里保留移植过程中的逆向证据、素材分析、实机基线、优化方案和修复记录。它们用于追溯实现依据；文中的“当前版本”、性能数字、构建路径和待办均指写作时的版本，不代表最新实现。后续日志可能修正前一轮判断，请结合文档注明的构建标记与取样范围阅读。

当前安装与构建入口见[项目 README](../../README.md)和[构建与工具链](../03-构建与工具链.md)。本目录不参与编译。

个人电脑路径和附件地址已替换为逻辑别名：`${PROJECT_ROOT}` 表示当时的项目目录，`${ASSET_ROOT}`、`${CAPTURE_ROOT}`、`${REVERSE_INPUT_ROOT}`、`${REFERENCE_PORT_ROOT}` 分别表示素材、捕获、逆向输入和参考移植工程。它们用于描述历史证据来源，不要求在本机设置这些变量；测量数值、逆向地址和文件内容哈希保持原值。未脱敏的原始捕获继续留在本地忽略目录中。
